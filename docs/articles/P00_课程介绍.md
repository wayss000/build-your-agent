# P00 课程介绍｜从零写一个自己的 Agent

用过 Codex，看过 Agent 读取文件、执行命令，但轮到自己开发，还是不知道从哪里开始？

模型调用、工具调用、Agent loop、Skill、记忆，概念越看越多。直接打开开源项目，入口在哪里、一次任务怎么跑起来，也很难一下看清楚。

**这套课程带你从一个 Python 终端程序开始，逐步写出能调用工具、根据执行结果继续工作的 loop Agent。** 每一步都有对应代码，你可以运行、修改，也可以对照前后版本理解变化。

## 学完基础篇，你能做什么？

你会写出一个在终端运行的 Agent。输入任务后，它可以请求模型、执行 Bash 工具，把结果交回模型，再继续下一步，直到回答或达到轮数上限。

- **会开发**：接入模型接口、管理配置、编写工具、实现 Agent 循环。
- **能解释**：分清模型生成调用请求、程序执行工具、结果回传模型这几个环节。
- **能排错**：通过日志定位接口错误、参数问题、命令失败和循环停止的原因。

基础篇的实践任务是生成项目说明。让 Agent 查看项目目录，读取 README、依赖配置和入口文件，整理出项目用途、结构与运行方式。你会核对输出，检查每个结论是否有文件依据。

## 为什么这样学？

**不知道从哪开始，就从最小程序开始。** 先写输入和回显，再接模型、配置和日志，随后开发 Bash 工具，完成模型调用工具与 Agent 循环。每课围绕一个明确的新能力展开。

**怕跟不上，可以停在某一课运行。** `study_step` 分支按教学顺序开发，代码章节有对应 tag。看不懂某次改动，就对比前后两个版本；自己的代码跑不通，也可以用本课快照对照排查。

**担心只会照着抄，就动手改变结果。** 改一个配置、换一条命令、观察一次失败，验证自己的理解。日志会帮助你检查实际执行过程。

**想看懂主流实现，先建立自己的参照。** 完成最小循环后，课程会以 Hermes 为例对照源码，追踪模型请求、工具执行和停止条件。带着具体问题读源码，更容易找到值得借鉴的设计。

## 需要什么基础？

能读懂简单 Python，了解变量、函数、循环和异常，就可以开始。不要求有 Agent 开发经验。环境准备会说明 Python、Git、Bash 和课程代码的使用方法。

你需要准备模型接口配置，调用可能产生费用。Bash 会实际执行命令，练习时使用可信、没有敏感信息的目录。模型输出仍需核对，课程也会练习失败处理。

## 目前学到哪里？

教学代码已完成到 P09 Agent 循环，已有逐章 tag。后续计划包括多轮对话、Skill、会话压缩和长期记忆，会根据反馈与开发时间继续推进。

Server 部署只讨论架构思路，不实现服务化代码。当前学习目标是完成一个自己能读懂、能修改、能在个人电脑上运行的 Agent。
