# Build Your Agent 课程章节目录（Review 草案）

面向新手：从零写出个人可用的 loop Agent，再通过 Hermes 源码学习进阶能力。
配套开源代码与 B站、YouTube 视频；本文件是课程规划，不表示功能已实现。

## 导学
- 00 课程介绍与环境准备：Python、Git、仓库使用及 Agent 完整任务演示。

## 基础篇：原理与实践，写出 loop Agent
- 01 Agent 是什么：模型、工具、消息与循环之间的关系。
- 02 终端对话程序：输入、回显、连续交互与退出。
- 03 调用大模型：请求接口、消息结构与文本回答。
- 04 模型配置：管理地址、密钥、模型名称与参数。
- 05 日志与观察：追踪输入、模型响应、耗时及失败。
- 06 Bash 工具：独立执行命令，理解输出、退出码与超时。
- 07 模型的工具调用：工具说明、参数、tool_calls 与结果回传。
- 08 Agent loop：连续调用工具、最终回答、异常与轮数限制。
- 09 ask_user 工具：向用户补充提问，再继续完成任务。
- 10 综合实践：完成需要提问与工具调用的任务，并排查失败。

## 源码篇：以 Hermes 为主线，对照开源实现
- 11 源码阅读方法：固定版本，从入口追踪一次请求的调用链。
- 12 Hermes 的 Agent loop：模型请求、工具执行与停止条件。
- 13 Hermes 的工具机制：工具定义、注册、查找与结果处理。
- 选修对照：PI、OpenClaw、DeepSeek Harness；核实项目与版本后，每次讨论一个设计问题。

## 高级篇：让 Agent 持续协作
- 14 多轮对话：维护当前会话历史，支持清空与上下文完整性。
- 15 Skill 原理与 Hermes 实现：区分操作指引和执行工具。
- 16 支持 Skill：选择并读取可信本地 Skill，结合工具执行。
- 17 开发 Skill：编写、验证并改进一个可复用的任务指引。
- 18 上下文压缩原理：token、长度限制与需要保留的信息。
- 19 实现会话压缩：摘要历史，保留任务状态与关键结果。
- 20 长期记忆与 Hermes 设计：区分聊天记录、用户偏好和任务经验。
- 21 最小长期记忆：使用本地存储，支持读取、保存、更新与删除。
- 22 让 Agent 更了解你：基于用户明确提供的信息调整协作方式。

## 使用与部署篇
- 23 个人电脑部署：安装、配置、启动、更新与恢复。
- 24 日常排障与使用边界：定位配置、模型和工具问题。
- 25 Server 部署思路：参考 Data-Flow 讨论请求入口、会话隔离与任务执行；不实现服务化代码。
