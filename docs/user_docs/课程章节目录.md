# 从零开发自己的 AI Agent（课程草案）

## 导学：让 AI 从回答问题到动手做事

- 00 你能学到什么：开发、理解并用上自己的 Agent
- 准备：Python 环境与课程代码使用方法

## 基础篇：写一个自己的 loop Agent

- 01 Agent 如何完成任务：模型、工具与循环
- 02 写一个能连续对话的终端程序
- 03 接入大模型，让程序真正回答问题
- 04 用配置切换模型，不用反复改代码
- 05 用日志看清 Agent 做了什么、哪里出错
- 06 开发 Bash 工具，让程序操作本地文件
- 07 让模型选择工具并生成调用参数
- 08 写出 Agent loop：执行工具，再根据结果继续
- 09 动手实践：让 Agent 查看项目并生成项目说明
- 10 开阔视野：Hermes 如何实现循环与工具调用
- 延伸对照：PI、OpenClaw、DeepSeek Harness 的设计思路

## 高级篇：让 Agent 能持续帮你做事

- 11 多轮对话：不用每次重新交代背景
- 12 理解 Skill：把任务方法交给 Agent（对照 Hermes）
- 13 支持 Skill：让 Agent 按指引完成任务
- 14 开发 Skill：把生成项目说明变成可复用流程
- 15 理解上下文限制：聊久了为什么会出问题
- 16 压缩会话：缩短历史，保留任务进展
- 17 理解长期记忆：Hermes 如何记住用户与经验
- 18 实现记忆：保存、读取、更新与删除信息
- 19 让 Agent 更了解你：记住偏好，减少重复说明

## 用起来：在自己的电脑上使用 Agent

- 20 安装与运行：把 Agent 变成日常工具
- 21 遇到问题怎么办：排查模型、工具与配置错误
- 22 如果搬到 Server：参考 Data-Flow，只讲思路，不写服务代码
