# 读取模型配置

> 状态：已实现；当前采用 `.env`，不是 README 中规划的 YAML。

## 本章开发目标

把模型地址、名称和密钥移出业务逻辑，让配置可以独立调整。

## 实现步骤

1. 将 `.env.example` 复制为 `.env`，填写 `NEW_API_KEY`、`MODEL_URL`、`MODEL_NAME`。
2. `MODEL_URL` 填完整 HTTPS Chat Completions 地址，包含接口路径。
3. 阅读 `src/config.py`：覆盖顺序为默认值 < `.env` < 环境变量。
4. 把 `MODEL_TEMPERATURE` 转为浮点数，`AGENT_MAX_ROUNDS` 转为正整数。
5. 缺少必填配置或格式不正确时，给出可读错误；配置文件不作为代码执行。

## 运行方式

执行 `python3 src/main.py`；默认温度为 0.7，默认最多调用模型 5 轮。

## 验收检查点

1. 缺少必填项时提示配置项名称。
2. 修改模型名称后，新请求使用新配置。
3. 环境变量与 `.env` 同时设置时，环境变量生效。

## 本章边界

不提交 `.env` 或真实密钥；本章不引入 YAML、配置热更新服务。
