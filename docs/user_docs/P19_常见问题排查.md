# P19 常见问题排查

> 适用于当前 CLI；高级功能按对应章节检查。

## 本章目标

按日志和执行结果定位问题，不盲目改代码。

## 实现步骤

1. 无法启动：检查 Python 版本、入口路径和当前目录。
2. 配置失败：检查必填项及环境变量覆盖，不打印密钥。
3. 模型失败：按请求 ID 查 MODEL_RESPONSE，核对地址、模型与 HTTP 状态码。
4. 工具失败：查 TOOL_RESULT 的 stderr、退出码和超时。
5. 达到轮数上限：查看循环记录，缩小任务，排查重复调用。
6. 记忆或 Skill 问题：完成相应能力后再检查来源、加载与清空操作。

## 验收检查

1. 能从一次失败日志找到出错阶段。
2. 修复后重试成功，分享日志前去除敏感内容。

## 本章边界

连接问题需同时检查网络与接口服务；历史日志不一定使用新版中文事件格式。
