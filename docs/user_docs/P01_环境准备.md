# P01 环境准备

> 本课快照为 study-p01，仅包含环境骨架，不含对话程序。

## 本章目标

准备 Python、Git 和 Bash，能启动当前项目。

## 实现步骤

1. 安装 Python 3.10+、Git 与 Bash；Windows 建议使用 WSL。
2. 克隆仓库，进入项目根目录；所有后续命令默认从这里执行。
3. 创建虚拟环境，激活后使用当前环境的 Python。
4. 复制 `.env.example` 为 `.env`，按模型配置章节填写；不要提交密钥。

## 运行方式

```bash
git clone https://github.com/wayss000/build-your-agent.git
cd build-your-agent
python3 -m venv .venv
source .venv/bin/activate
cp .env.example .env
git switch --detach study-p01
```

## 验收检查

1. `python3 --version`、`git --version`、`bash --version` 能正常执行。
2. 能创建并激活虚拟环境，仓库中的课程文档可阅读。
