# 调用模型

> 状态：已实现。

## 本章开发目标

把用户输入发送给兼容 Chat Completions 的接口，显示模型回答。

## 实现步骤

1. 阅读 `src/model.py`，使用标准库 `http.client.HTTPSConnection` 发起请求。
2. 构造 `model`、`messages`、`temperature`；用户内容放在 `user` 消息中。
3. 用 JSON 编码请求体，认证信息放在 `Authorization` 请求头。
4. 设置 60 秒连接超时，检查 HTTP 状态码。
5. 从 `choices[0].message` 读取 assistant 消息，并校验响应格式。
6. 在 `finally` 中关闭连接；CLI 捕获异常后继续等待下一次输入。

## 运行方式

完成 P3 配置，运行 `python3 src/main.py`，输入“用一句话解释 Python”。

## 验收检查点

1. 终端显示模型返回的文本，而非固定回显。
2. 接口失败时显示简明提示，并保留日志用于排查。

## 本章边界

本章练习先关注文本回复；当前版本也会发送工具说明。暂不实现流式输出和自动重试。
