# 加载 Skill

> 状态：待实现；本章是后续练习，不代表当前已有功能。

## 本章开发目标

让 Agent 按任务读取可复用的文字指引，并结合工具执行。

## 实现步骤

1. 约定本地 Skill 目录，每个 Skill 使用 `SKILL.md` 保存名称、用途和步骤。
2. 先加载名称与摘要，根据用户任务选择需要的 Skill。
3. 选中后读取完整内容，作为任务上下文交给模型。
4. 明确 Skill 是操作指引，实际动作仍由已注册工具执行。
5. 处理文件缺失和格式错误，在日志中记录选中的 Skill。

## 运行方式

完成前置章节后按本章步骤开发，再使用下方验收点检查。

## 验收检查点

1. 匹配任务时加载指定 Skill，并按其步骤完成任务。
2. 无匹配 Skill 时仍能正常对话；缺失文件有清晰提示。

## 本章边界

先支持可信本地文本，不引入远程市场、自动安装或执行 Skill 中的任意脚本。
