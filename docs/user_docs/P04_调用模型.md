# P04 调用模型

> 已实现，参考 `src/model.py`。

## 本章目标

把固定回显换成真实模型回答。

## 实现步骤

1. 准备兼容 Chat Completions 的 HTTPS 接口、密钥与模型名称。
2. 构造 `model` 与 `messages`，用户内容放入 user 消息。
3. 用标准库发送 JSON 请求，将密钥放在 Authorization 请求头。
4. 读取 `choices[0].message`，校验响应并显示文本。
5. 设置超时，处理 HTTP 错误，在 finally 中关闭连接。

## 验收检查

1. 输入“用一句话解释 Python”，得到模型回复。
2. 接口失败时给出提示，仍能继续输入。

## 本章边界

本章先不发送工具；当前版本会发送工具说明。真实密钥不写进源码或日志。
