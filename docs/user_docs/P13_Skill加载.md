# P13 Skill加载

> 待实现；前置：Agent 循环与多轮对话。

## 本章目标

读取任务指引，让 Agent 按可复用的方法工作。

## 实现步骤

1. 解释 Skill 是文字指引，实际动作仍由工具完成。
2. 约定本地目录与 SKILL.md，先显式选择一个 Skill。
3. 读取指引并交给模型，记录加载的 Skill。
4. 处理文件缺失与格式错误，再按需要增加名称和摘要选择机制。
5. 对照固定版本的 Hermes，了解它如何发现与加载 Skill。

## 验收检查

1. 指定 Skill 后，Agent 按指引执行。
2. 缺失 Skill 时有提示，终端仍可继续使用。

## 本章边界

先支持可信本地文件，不做插件市场或自动安装。
