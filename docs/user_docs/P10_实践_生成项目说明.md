# P10 实践：生成项目说明

> 可用当前 Bash 与 Agent 循环完成，输出需要人工核对。

## 本章目标

让 Agent 阅读真实项目，生成有依据的项目说明。

## 实现步骤

1. 选一个无敏感信息的小项目，在项目根目录启动 Agent。
2. 要求先查看目录，再读取 README、依赖配置与入口文件。
3. 明确任务：“在终端生成项目说明，包含用途、目录和运行方式，标明未知信息，不修改文件。”
4. 查看工具日志，确认 Agent 实际读过用于说明的文件。
5. 人工核对说明，确认后再保存为单独文档。

## 验收检查

1. 说明中的目录、依赖与启动命令可以在源码中找到依据。
2. 缺少信息时明确说明，不编造功能或配置。

## 本章边界

先做只读任务，不自动修改 README；内容过多时缩小读取范围。
