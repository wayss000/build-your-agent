# 模型调用工具

> 状态：已实现。

## 本章开发目标

完成用户输入 → 模型 → 工具 → 模型 → 最终回答的闭环。

## 实现步骤

1. 阅读 `src/agent.py`，为一次输入建立 system 和 user 消息。
2. 向模型发送工具说明；模型返回 `tool_calls` 时解析工具名称和 JSON 参数。
3. 先追加 assistant 消息，再执行工具，并追加对应的 tool 消息。
4. 用 `tool_call_id` 对应原始调用；工具结果序列化为 JSON 字符串。
5. 把工具结果交给下一轮模型；没有工具调用时返回最终文本。
6. 工具失败也回传模型；达到轮数上限时停止，最后一轮不再执行新工具。

## 运行方式

运行 CLI，输入“请调用 Bash 查看当前目录，并解释结果”。

## 验收检查点

1. 日志出现 `TOOL_STARTED`、`TOOL_RESULT`，之后模型继续回答。
2. 回答依据实际执行结果；未知工具或参数错误得到错误结果。

## 本章边界

每轮指一次模型请求；当前每次用户输入独立建上下文，不保留跨请求记忆。
