# P11 主流Agent的循环实现

> 源码课，以 Hermes 为主；具体仓库与提交版本待选定。

## 本章目标

对照真实源码，理解自己的循环与主流实现的异同。

## 学习步骤

1. 固定 Hermes 的仓库与提交号，记录源码链接。
2. 从一次用户输入追踪模型请求、工具调用和结果回传。
3. 找到循环停止、错误处理及工具注册入口。
4. 与自己的 Agent 对照：哪些逻辑相同，哪些为额外能力服务。
5. 按需选 PI、OpenClaw、DeepSeek Harness 对照一个设计问题。

## 验收检查

1. 能用实际源码位置解释完整循环。
2. 能说明一种值得借鉴的设计及适用条件。

## 本章边界

不要求读完整个项目；未核实源码前不猜测文件路径或实现细节。
