# P20 Server部署思路

> 讨论课；不实现服务化代码，参考 Data-Flow。

## 本章目标

了解本地 Agent 演进为服务需要解决的问题。

## 学习步骤

1. 先固定 Data-Flow 项目与版本，确认参考的实际架构。
2. 讨论终端输入如何改为请求入口，以及任务结果如何返回。
3. 讨论多个用户的会话、工作目录与权限如何隔离。
4. 讨论任务超时、中断、重试和工具执行的重复副作用。
5. 了解持久化、日志、进程管理及多实例部署的取舍。

## 验收检查

1. 能画出入口 → Agent → 工具 → 结果的服务流程。
2. 能指出 CLI 直接放到 Server 上缺少哪些能力。

## 本章边界

本章仅拓展视野，不要求开发 API、队列或多 Server 系统。
