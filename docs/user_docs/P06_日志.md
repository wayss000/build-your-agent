# P06 日志

> 使用 study-p06，参考 `src/log_event.py`。

## 本章目标

能通过日志看清请求过程并定位失败位置。

## 实现步骤

1. 每次用户输入生成请求 ID，一次请求的所有事件复用它。
2. 追加写入 `logs/app.log`，记录时间、ID、模块、事件和内容。
3. 用 LogEvent 集中管理事件及中文说明。
4. 本章记录输入、模型请求与响应、最终回答或失败；工具事件随后接入。
5. 用 perf_counter 计算耗时；请求失败后继续交互。

## 验收检查

1. 新日志显示 `INPUT_RECEIVED（已收到用户输入）` 等事件。
2. 多个请求追加记录，同一请求可按 ID 串联。

## 本章边界

日志包含输入和工具输出，分享前检查敏感内容；不记录认证头。
