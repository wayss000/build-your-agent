# P05 模型配置

> 已实现，采用 `.env`，参考 `src/config.py`。

## 本章目标

修改配置即可切换模型，不改业务代码。

## 实现步骤

1. 复制 `.env.example` 为 `.env`。
2. 填写 `NEW_API_KEY`、`MODEL_URL`、`MODEL_NAME`；URL 包含完整 HTTPS 接口路径。
3. 合并默认值、文件和环境变量，环境变量优先。
4. 转换温度和轮数的类型，缺少必填项时给出明确提示。

## 验收检查

1. 更换可用模型名称后，新请求使用新模型。
2. 环境变量覆盖同名文件配置；缺项时提示名称。

## 本章边界

默认温度 0.7，最多 5 轮；调用模型章节先准备配置值，本章再整理成配置模块。
