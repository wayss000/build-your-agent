# 单机部署

> 状态：待实现；本章是后续练习，不代表当前已有功能。

## 本章开发目标

让 Agent 在一台机器上可重复安装、启动和排查。

## 实现步骤

1. 准备 Python 3.10+ 与 Bash，使用虚拟环境安装项目。
2. 配置模型地址和凭据，确认运行用户的工作目录与文件权限。
3. 使用 `build-your-agent` 或 `python3 src/main.py` 做终端交互验收。
4. 记录安装步骤、日志位置、更新方式和回退到旧版本的方法。
5. 需要后台服务时，先增加适合服务运行的请求入口，再配置进程守护。

## 运行方式

完成前置章节后按本章步骤开发，再使用下方验收点检查。

## 验收检查点

1. 新环境按文档可启动，模型和两个工具可用。
2. 退出码和日志可用于排查；更新失败时有明确恢复步骤。

## 本章边界

当前入口依赖终端 input，不能直接当作无人值守服务；本章不做多实例部署。
