# 启动脚本

> 状态：已实现；拉取前需要为当前分支设置上游。

## 本章开发目标

用一个脚本拉取当前分支更新，并启动终端 Agent。

## 实现步骤

1. 阅读根目录 `start.sh`，使用 `set -euo pipefail` 在失败时退出。
2. 定位脚本所在目录并切换到仓库根目录。
3. 执行 `git pull --ff-only`，只接受快进更新，分叉时停止。
4. 使用 `exec python src/main.py` 启动，让 Python 接收终端信号和退出码。
5. 确保 `python` 指向 Python 3.10+，并提前准备模型配置。

## 运行方式

执行 `bash start.sh`；本地 work 对应远程 work 时，可先执行：
```bash
git branch --set-upstream-to=origin/work work
```
只启动、不拉取时使用 `python3 src/main.py`。

## 验收检查点

1. 成功拉取后进入终端交互。
2. 拉取失败时脚本退出，不继续启动旧代码。

## 本章边界

本章不处理自动合并冲突、后台守护或生产发布。
