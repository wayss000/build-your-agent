# P03 开发CLI

> 使用 study-p03：本章只实现回显，不调用模型。

## 本章目标

写出支持连续输入、回显和退出的终端程序。

## 实现步骤

1. 在 `src/main.py` 放启动入口，`src/cli.py` 放交互逻辑。
2. 用 `input()` 读取输入，`print()` 回显“hello，你输入的是：xxx”。
3. 用 `while` 连续交互，空白输入跳过。
4. 输入 `exit` 退出，捕获 Ctrl+C 和 Ctrl+D，正常结束程序。

## 验收检查

1. 连续输入两次，都得到对应回显。
2. 空白输入不产生回复，退出方式均有效。

## 本章边界

在 study-p03 执行 `python3 src/main.py`；教学最新版已包含后续能力。
