# 对话记忆

> 状态：待实现；本章是后续练习，不代表当前已有功能。

## 本章开发目标

先保留同一会话的上下文，再学习跨启动的持久化记忆。

## 实现步骤

1. 将 messages 从单次 `run_agent()` 内移到会话对象中维护。
2. 每次输入追加 user 消息，保留 assistant 与配套的 tool 消息。
3. 提供清空会话操作，并限制上下文长度，避免无限增长。
4. 需要跨启动记忆时，再选择本地 JSON 或 SQLite 保存会话。
5. 区分对话记录和长期偏好，保存偏好前让用户明确确认。

## 运行方式

完成前置章节后按本章步骤开发，再使用下方验收点检查。

## 验收检查点

1. 先说“我喜欢 Python”，下一次输入询问偏好时能回答。
2. 清空会话后不再沿用旧信息；裁剪不产生孤立工具消息。

## 本章边界

先做会话历史，不引入向量数据库；当前代码每次请求独立，尚无此能力。
