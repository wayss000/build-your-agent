# P18 单机部署

> 当前 CLI 可用；高级能力需完成对应章节。

## 本章目标

在个人电脑上安装、运行并更新 Agent。

## 实现步骤

1. 准备 Python 3.10+ 和 Bash，创建虚拟环境。
2. 从仓库安装项目，准备 .env 与模型接口配置。
3. 在目标工作目录启动，检查 Bash 实际执行位置。
4. 记录版本与更新方式；更新失败时回到已确认的版本。

## 运行方式

```bash
python3 -m pip install .
# 填写配置后，可从目标工作目录启动
build-your-agent
```

## 验收检查

1. 能在个人电脑启动，完成一次模型回答和工具调用。
2. 知道日志位置，能正常退出并重新启动。

## 本章边界

当前依赖终端输入；不配置为无人值守服务，不在不可信目录执行模型命令。
