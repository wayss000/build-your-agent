# P14 Skill开发

> 待实现；前置：Skill 加载。

## 本章目标

把生成项目说明整理成可以重复使用的 Skill。

## 实现步骤

1. 编写 SKILL.md，说明用途、输入和输出。
2. 规定流程：查看目录、读取关键文件、总结用途与运行方式。
3. 要求引用实际文件，区分事实与推测，不读取密钥。
4. 明确仅输出说明，不直接修改项目文件。
5. 在两个小项目上运行，根据遗漏和错误改进指引。

## 验收检查

1. 不同项目都能生成结构清楚、有依据的说明。
2. 缺少入口或配置时指出未知，不编造答案。

## 本章边界

Skill 不替代代码，也不保证模型每次完全遵循；需要检查实际结果。
