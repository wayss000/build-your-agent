# 多 Server 部署

> 状态：待实现；本章是后续练习，不代表当前已有功能。

## 本章开发目标

在完成服务化后，让多个实例处理请求并隔离不同会话。

## 实现步骤

1. 先定义 HTTP 等服务入口，把终端交互和 Agent 执行逻辑分离。
2. 用会话 ID 隔离消息历史；ask_user 改为等待客户端提交回答。
3. 部署多个实例，通过负载均衡分发请求。
4. 按需要接入共享会话存储或任务队列，处理并发和重试。
5. 隔离工具执行目录与权限，增加健康检查、集中日志和发布回退。

## 运行方式

完成前置章节后按本章步骤开发，再使用下方验收点检查。

## 验收检查点

1. 不同用户不会共享上下文或工具工作目录。
2. 实例重启、重复请求和超时有明确处理策略。
3. 一次请求的日志可以跨服务追踪。

## 本章边界

本章是后续设计，当前 CLI 尚不具备服务入口、共享存储或多实例能力。
