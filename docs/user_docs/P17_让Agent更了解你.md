# P17 让Agent更了解你

> 待实现；前置：长期记忆。

## 本章目标

用明确的偏好减少重复说明，同时让用户能纠正记忆。

## 实现步骤

1. 选择具体偏好，例如解释深度、编程语言或输出格式。
2. 用户要求记住后保存；推测出的偏好先询问确认。
3. 在相关任务中使用偏好，当前明确指令优先。
4. 让用户查看、纠正或删除信息。
5. 对照 Hermes 的用户信息机制，讨论适用范围。

## 验收检查

1. 保存“请用中文解释”后，新会话的相关回答遵循偏好。
2. 用户临时要求英文时，以本次要求为准。

## 本章边界

这里的“你”指用户；不把用户偏好与 Agent 身份设定混为一谈。
