## 本章开发目标

开发一个最小的 Python 终端对话程序：程序等待用户输入，记录一条日志，再把输入内容回显给用户。

## 实现步骤

1. 使用 `input()` 从终端读取用户通过键盘输入的内容。
2. 使用 `logging` 记录收到的输入，便于在后台排查程序运行情况。
3. 使用 `print()` 将“你刚才输入的是：xx”输出到终端。
4. 使用 `while` 循环让程序可以连续对话；输入 `exit`，或按下 `Ctrl+C`，即可退出。

## 运行方式

在项目根目录执行：

```bash
python3 src/build_your_agent/main.py
```

## 验收check点

1. 在日志文件中，logs/app.log 中出现代码中 log.info 中的日志

## 不要实现什么

1. 不调用大模型。
2. 不读取配置文件。
3. 不实现工具调用、记忆、MCP 或部署能力。
