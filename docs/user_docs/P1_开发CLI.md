# 开发 CLI

> 状态：已实现；当前入口已接入 Agent，回显是本章练习目标。

## 本章开发目标

使用 Python 3.10+，先做一个能连续输入、回显和退出的终端程序。

## 实现步骤

1. 在 `src/main.py` 中保留启动入口，交互逻辑放到 `src/cli.py`。
2. 用 `input("你：")` 读取输入，用 `print()` 输出“hello，你输入的是：xxx”。
3. 用 `while` 支持连续输入；空白输入直接跳过。
4. 输入 `exit` 时结束循环，捕获 `EOFError`、`KeyboardInterrupt` 正常退出。
5. 让 `main()` 返回退出码，使用 `raise SystemExit(main())` 启动。

## 运行方式

在仓库根目录执行 `python3 src/main.py`。
当前版本实际对话需要先按 P3 配置模型；本章回显练习不需要模型。

## 验收检查点

1. 连续输入两条内容，每条都能得到回显。
2. 空白输入不产生回复；`exit`、Ctrl+C、Ctrl+D 均能退出。

## 本章边界

本章只实现终端交互，不增加模型、工具或记忆。
