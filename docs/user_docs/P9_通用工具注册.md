# 通用工具注册

> 状态：待实现；本章是后续练习，不代表当前已有功能。

## 本章开发目标

统一工具说明和执行入口，新增工具时减少对 Agent 主循环的修改。

## 实现步骤

1. 定义工具约定：名称、模型可读的说明、接收参数字典的执行函数。
2. 为 Bash 增加适配层，将 `BashResult` 转为字典；ask_user 同样返回字典。
3. 建立按名称索引的注册表，注册 Bash 和 ask_user，拒绝重复名称。
4. 从注册表生成发送给模型的工具说明列表。
5. Agent 根据名称查找工具，统一执行、记录日志和回传结果。

## 运行方式

完成前置章节后按本章步骤开发，再使用下方验收点检查。

## 验收检查点

1. 两个现有工具仍能正常调用。
2. 新增一个简单工具时，Agent 主循环不需要新增分支。
3. 未知工具和重复注册有明确错误。

## 本章边界

先实现 Python 注册表；配置化加载、插件安装和动态导入留到后续。
