# 访问外部数据与 MCP

> 状态：待实现；本章是后续练习，不代表当前已有功能。

## 本章开发目标

先用外部 CLI 查询数据，再理解通过 MCP 接入工具的方式。

## 实现步骤

1. 选择一个明确的数据查询场景，准备可用 CLI 和所需认证。
2. 用 Bash 调用 CLI，解析返回结果；先限定为只读查询。
3. 学习 MCP 的客户端、服务端、工具发现和工具调用流程。
4. 连接一个 MCP 服务端，把发现的工具适配到本项目注册表。
5. 处理工具名称冲突、连接超时和认证失败，记录调用结果。

## 运行方式

完成前置章节后按本章步骤开发，再使用下方验收点检查。

## 验收检查点

1. CLI 查询能根据真实数据回答。
2. MCP 工具可被发现并调用，失败时仍可继续终端对话。

## 本章边界

外部服务由用户选择；不把密钥写进日志，本章不实现远程写操作或完整 MCP 服务端。
