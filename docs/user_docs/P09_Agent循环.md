# P09 Agent循环

> 使用 study-p09，参考 `src/agent.py`。

## 本章目标

让模型根据工具结果继续工作，直到输出最终回答。

## 实现步骤

1. 建立 system、user 消息，进入有限轮数的循环。
2. 无 tool_calls 时返回文本；有调用时先保存 assistant 消息。
3. 执行工具，再追加 tool 消息，通过 tool_call_id 对应原调用。
4. 把结果序列化为字符串，交给下一轮模型。
5. 失败结果也回传；最后一轮不再执行新工具。

## 验收检查

1. 工具执行后，日志出现下一轮模型请求。
2. 轮数到达上限时停止，并给出明确错误。

## 本章边界

每次用户输入重建上下文；本教学分支只有 Bash 工具，不包含 ask_user。
