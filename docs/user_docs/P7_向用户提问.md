# 向用户提问

> 状态：已实现；当前第二个工具为 `ask_user`。

## 本章开发目标

让模型在信息不足时向用户提问，再根据回答继续任务。

## 实现步骤

1. 阅读 `src/tools/ask_user_tool.py`，工具参数为非空字符串 `question`。
2. `execute()` 输出问题，通过 `input()` 等待用户回答。
3. 空白回答提示重输，有效回答返回 `{"answer": "用户输入"}`。
4. Agent 同时发送 Bash 和 ask_user 的说明，按工具名称分派执行。
5. 把用户回答作为 tool 消息交给下一轮模型；Ctrl+C、Ctrl+D 交给 CLI 处理退出。

## 运行方式

运行 CLI，输入“请先用 ask_user 问我喜欢的编程语言，再介绍它”。

## 验收检查点

1. 终端显示 Agent 提问，输入回答后继续生成回复。
2. 回答为空时重新询问；日志能追踪提问参数与回答结果。

## 本章边界

本章只支持终端单行文本回答，不实现选项菜单、网页表单或持久化用户偏好。
