# P08 模型调用工具

> 已实现，参考 `src/model.py` 与 `src/agent.py`。

## 本章目标

让模型选择工具并生成参数，由程序实际执行。

## 实现步骤

1. 把 Bash 的工具说明放进请求的 tools 列表。
2. 查看模型返回的 tool_calls，读取名称、调用 ID 与 arguments。
3. 将 arguments 从 JSON 字符串解析成字典并校验。
4. 按工具名称调用函数，保留真实结果和错误。

## 验收检查

1. “请调用 Bash 查看当前目录”能产生工具调用。
2. 能指出模型生成参数与 Python 执行命令的分界。

## 本章边界

先理解一次调用；工具结果回传与连续执行在下一章完成。模型是否调用工具取决于请求与模型能力。
