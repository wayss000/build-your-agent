# P15 会话压缩

> 待实现；前置：多轮对话。

## 本章目标

在上下文变长时保留任务进展，减少历史负担。

## 实现步骤

1. 解释 token 与上下文上限，选择一个明确的压缩触发条件。
2. 把较早历史总结为目标、约束、已完成事项与待办。
3. 保留最近消息；压缩完整的工具调用与结果，不留下孤立 tool 消息。
4. 用摘要替换旧历史，保留原记录便于排查。
5. 摘要失败时保留原消息并提示，不继续发送超出限制的请求。

## 验收检查

1. 压缩后仍能回答当前目标，并继续未完成任务。
2. 模型接收到的历史更短，工具消息仍配对完整。

## 本章边界

摘要可能丢信息；不把压缩摘要直接当作长期记忆。
