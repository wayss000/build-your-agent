# P00 课程介绍

> 课程规划，教学分支与 tag 尚未建立。

## 本章目标

理解课程目标，知道每一步学完能做什么。

## 学习步骤

1. 从终端输入开始，逐步接入模型、Bash 工具和 Agent 循环。
2. 用“生成项目说明”检验基础能力，再把操作方法整理成 Skill。
3. 学习多轮对话、压缩和记忆，让 Agent 能持续协作。
4. 以 Hermes 为例对照源码，最后在个人电脑上使用。

## 验收检查

1. 能解释本课程最终要做出的 Agent。
2. 能区分模型回答、工具执行和 Agent 循环。

## 本章边界

需要能读懂简单 Python；服务部署只讨论思路，不实现服务化。
