# 核心实现

实现 CLI → Agent → 模型 → Bash → 模型的最小循环，无第三方运行依赖。

- 使用 `.env` 配置，环境变量优先；不执行配置内容或变量插值。
- MODEL_URL 为完整的 HTTPS Chat Completions 接口地址。
- 每个用户请求使用独立消息列表，不实现跨请求记忆。
- 每次 Bash 调用在当前工作目录启动独立进程，默认等待 30 秒，返回 stdout、stderr、returncode；失败结果回传给模型。
- AGENT_MAX_ROUNDS 限制模型调用次数，最后一轮请求工具时不再执行。
- 日志写入 logs/app.log，以请求 ID 串联输入、模型请求/响应、工具执行和最终结果。日志含对话与命令输出，不记录认证头。
- Bash 直接执行模型生成的命令，只在可信的本地环境使用；没有沙箱或审批机制。超时终止直接子进程，不保证清理命令派生的所有后台进程。

运行：复制 .env.example 为 .env 并填写配置，然后执行 `python3 src/main.py`。也可以安装项目后使用 `build-your-agent`。

目录采用 src 平铺模块，工具位于 src/tools；打包时显式声明顶层模块。
